# CRDT 실시간 공동 편집 데모

문자를 위치가 아닌 고유 ID와 부모 원소(`after`)로 표현하는 간단한 RGA 계열 CRDT 발표용 웹 앱입니다. 서버는 연산을 저장·중계하고, 브라우저는 어떤 도착 순서에서도 결정론적으로 원소를 병합합니다.

## 실행

```powershell
npm install
npm start
```

브라우저에서 `http://localhost:3000?room=발표방이름`을 열고, 같은 주소를 여러 창에서 엽니다. 방 이름이 같으면 같은 문서를 편집합니다.

## 온라인 발표 배포

이 폴더를 하나의 Git 저장소로 올린 뒤 Render의 **Web Service**로 연결하면 됩니다.

| 설정 | 값 |
| --- | --- |
| Runtime | Node |
| Build Command | `npm install` |
| Start Command | `npm start` |

`PORT` 환경 변수는 배포 플랫폼이 주입한 값을 자동 사용합니다. 배포된 `https://.../?room=crdt-presentation` 링크를 참가자에게 공유하면 서로 다른 Wi-Fi에서도 같은 방에 접속합니다.

> 서버 메모리는 실행 중에만 유지됩니다. 발표 전 새 방 이름을 사용하면 빈 문서로 시작할 수 있습니다.

## 발표 시연 제안

두 사람이 같은 위치에 동시에 다른 글자를 입력합니다. 각 브라우저가 같은 ID 순서로 원소를 정렬해 문서가 수렴하는 점과, 오른쪽의 **고유 원소**·**삭제 표식** 수치를 함께 보여주면 됩니다.
